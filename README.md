## Different Viewport Sizes
### Screen (960px+)
I picked this size because generally full-sized screens are at or above this size. This guarantees that content will not be missing.

### Tablet (481px-960px)
For tablets I picked 481-960px because its between full sized screens and phones. Additionally while monitors generally have the same standard sizes tablets can vary widely in size. This rule catches anything inbetween.

### Phone (Under 480px)
For phones, I picked under 480px. Like tablets size can vary alot between devices but they require special considerations due to very small screen size.
